# Budgetly PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert Budgetly into a fully installable, responsive, standalone Progressive Web App (PWA) with conservative Workbox caching and automatic updates.

**Architecture:** Integrate `vite-plugin-pwa` into the Vite build pipeline, sync web app manifest and icons, register the service worker on app bootstrap, ensure meta tag compliance, and polish mobile viewports.

**Tech Stack:** React 19, Vite 7, `vite-plugin-pwa`, Workbox, Tailwind CSS v4.

---

### Task 1: Install `vite-plugin-pwa`

**Files:**
- Modify: `client/package.json`

- [ ] **Step 1: Install `vite-plugin-pwa` dependency in client**
Run: `npm --prefix client install -D vite-plugin-pwa`

- [ ] **Step 2: Verify installation in `client/package.json`**
Inspect `client/package.json` devDependencies.

---

### Task 2: Configure Vite PWA Plugin & Manifest

**Files:**
- Modify: `client/vite.config.js`
- Modify: `client/public/site.webmanifest`

- [ ] **Step 1: Update `client/vite.config.js` with VitePWA plugin**
Configure `VitePWA` with `registerType: 'autoUpdate'`, Workbox static globPatterns, and explicit manifest metadata (name, short_name, description, theme_color `#ca8a04`, background_color `#ffffff`, standalone display, orientation, icons with maskable purpose).

- [ ] **Step 2: Sync `client/public/site.webmanifest`**
Update `client/public/site.webmanifest` to match all attributes so direct references are consistent.
